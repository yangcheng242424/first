# 📱 手机端Cursor控制演示

这是一个展示如何在手机上使用Cursor进行编程和程序管理的演示项目。

## ✨ 功能特性

### 🎯 核心功能
- **代码编辑器**：支持多语言代码编辑，带行号显示和语法高亮
- **代码运行**：模拟代码执行，展示运行结果
- **代码保存**：本地存储代码，支持持久化
- **代码格式化**：自动格式化代码，提高可读性

### 🚀 快捷操作
- **🎤 语音输入**：使用手机语音输入快速编写代码
- **🤖 AI助手**：AI生成代码片段，提高编程效率
- **🔍 代码搜索**：快速搜索代码中的关键词
- **📦 Git操作**：在手机上管理Git仓库
- **💻 终端**：执行终端命令
- **📁 文件管理**：管理项目文件

### 👆 手势控制
- **单击**：选择/点击
- **双击**：选中单词
- **三击**：选中整行
- **双指缩放**：调整字体大小
- **长按**：显示上下文菜单
- **左右滑动**：撤销/重做操作

## 🎨 界面特点

- **响应式设计**：完美适配手机屏幕
- **现代化UI**：采用iOS风格设计，美观易用
- **触摸优化**：针对手机触摸操作进行优化
- **流畅动画**：平滑的过渡效果，提升用户体验

## 📖 使用方法

### 1. 打开项目
直接在手机浏览器中打开 `index.html` 文件，或通过Web服务器访问。

### 2. 编辑代码
- 点击代码编辑器区域开始输入代码
- 使用系统键盘或语音输入
- 支持Tab键自动缩进
- 双击选中单词，三击选中整行

### 3. 运行代码
- 点击右上角的 ▶️ 按钮运行代码
- 或使用快捷键 Ctrl/Cmd + Enter
- 运行结果会显示在底部控制台

### 4. 保存代码
- 点击 💾 按钮保存代码
- 代码会自动保存到浏览器本地存储
- 下次打开会自动加载保存的代码

### 5. 格式化代码
- 点击 ✨ 按钮格式化代码
- 自动整理代码缩进和格式

### 6. 使用快捷操作
点击底部快捷操作面板中的按钮：
- **语音输入**：使用语音输入代码
- **AI助手**：让AI生成代码
- **代码搜索**：搜索代码内容
- **Git操作**：执行Git命令
- **终端**：运行终端命令
- **文件管理**：管理项目文件

### 7. 手势操作
- **左滑**：撤销操作
- **右滑**：重做操作
- **双指缩放**：调整编辑器字体大小
